개인정보처리방침

시행일: 2026-11-26

1. 목적

'LG U+ 요금 정산'(이하 "앱")은 운영자 본인의 Gmail에 수신된 통신비 청구서를 처리하기 위한 개인용 도구입니다.

2. 접근하는 데이터

  • Gmail: 청구서 메일 검색, 청구서 HTML 첨부파일 읽기, 처리 완료 라벨 적용 (gmail.modify 범위)
  • 메일 삭제, 발송, 보관 처리는 하지 않습니다.

3. 이용 및 보관

  • 청구서는 실행 중 임시로 복호화되어 구성원별 금액 계산에만 사용되며, 실행이 끝나면 즉시 삭제됩니다.
  • 계산 결과는 운영자 본인의 카카오톡 '나에게 보내기'로만 전송됩니다.
  • 데이터를 제3자에게 판매하거나 제공하지 않으며, 광고 목적으로 사용하지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API에서 받은 정보의 사용 및 이전은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

5. 권한 철회

Google 계정의 '타사 앱 및 서비스' 설정에서 언제든지 앱의 접근 권한을 철회할 수 있습니다.
